# P2-9 — 35 Hz tick research Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Доказать точную сетку тика оригинала, найти всех потребителей шага и выдать декомпозицию перевода порта на 35 Гц.

**Architecture:** Research-only: Ghidra/decompiled xrefs строк `sv_fps`/`sv_game_speed`, разбор главного цикла, инвентаризация 60 Гц в порте и impact matrix; один документ `docs/research/p2-9-35hz.md`.

**Tech Stack:** Ghidra headless (`.local/decomp`), PowerShell/grep, optional user-assisted read-only live measurement.

## Global Constraints

- Research-only: не менять `src/`, `tests/`, `tools/`, не менять production-поведение.
- Скрипты/артефакты — только `%TEMP%`, не коммитить.
- Факты: файл + SHA-256 + RVA/offset + decompiled.c line/instrument.
- Не выдавать `sv_fps=35` за доказанный период, пока не найден цикл/формула; при неоднозначности — `unverified` + exact next check.
- Документы UTF-8 без BOM/NUL; markdown через edit/write.
- Коммиты docs-only после approve.

**Files:**
- Create: `docs/research/p2-9-35hz.md` (§Evidence)
- Read: `.local/decomp/client/decompiled.c`, `.local/decomp/server/decompiled.c`,
  `GoldenLand.exe` strings/decomp

- [ ] **Step 1: Locate strings and references**

```powershell
Select-String -Path .local\decomp\client\decompiled.c,.local\decomp\server\decompiled.c `
  -Pattern "sv_fps|sv_game_speed|timeGetTime|Sleep|frame" |
  ForEach-Object { "$($_.Filename):$($_.LineNumber): $($_.Line.Trim())" }
```

Expected: строки `sv_fps`, `sv_game_speed` (хотя бы в Client), вызовы
`timeGetTime`/`Sleep`/цикл. Записать RVA/lines.

- [ ] **Step 2: Ghidra xrefs (если decompiled не даёт callers)**

```powershell

$proj="$env:TEMP\ghidra_proj"
& .local\toolchains\ghidra_12.1.4_PUBLIC\support\analyzeHeadless.bat `
  $proj glclient -process Client.dll -noanalysis `
  -scriptPath "$env:TEMP" -postScript "DecompileAt.java"
```

Найти функцию, читающую `sv_fps`/`sv_game_speed`, и её callers; записать
RVA, decompiled lines, как значение влияет на цикл.

### Task 2: Tick model (exact period)

**Files:** `docs/research/p2-9-35hz.md` (§Tick model)

- [ ] **Step 1: Find the main loop**

Search decompiled for `timeGetTime` callers and frame scheduling; record
function RVA/lines, accumulator/Sleep/computation. If the loop is in
`GoldenLand.exe` (host), search its decomp/strings; if unavailable, mark
`unverified` and give exact Ghidra target.

- [ ] **Step 2: Derive the period**

Determine whether the original uses:
`1000/35 = 28.571 ms` (fixed tick), integer `28`/`29` ms, or a
`timeGetTime`-quantized loop. Record formula, rounding, and `sv_game_speed`
effect. Cross-check with D-033 live movement evidence (80→~63 ms, 85→~68 ms;
tick 35 → 56/84 ms). A live read-only measurement is allowed only if static
evidence is ambiguous; document user steps.

- [ ] **Step 3: Write §Tick model** with exact period, accumulator, max frame,
  `tick_index`/time mapping, and explicit `unverified` items.
