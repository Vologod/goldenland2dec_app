# P2-15b1b3 — RGINF Gate and Loot Ordering Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Apply the `+0x26c0` RGINF decision and chance-gated c0/c1 regeneration on save load, in `BT_ENTS` order, without the current ungated loot/person-init pass.

**Architecture:** A new `game::rginf` module converts the saved latch/datetime and `BT_INFO.time` into a runtime decision using Gregorian day arithmetic. `NpcLootGenerator::generate` gains a restore gate (`optional` + `force`), and `regenerate_npc_inventories` applies it to selected person indices. `RestoreResult` carries a per-person `loot_regenerate` flag; `glgame` orchestrates restore → decision → gated regeneration → SEF-only fallback, leaving the New Game path untouched.

**Tech Stack:** C++20, CMake + Ninja, doctest, SDL2 project layers (`assets` → `game` → `tools/glgame`).

**Spec:** `docs/specs/2026-11-15-p2-15b1b3-rginf-gate-design.md`.

## Global Constraints

- C++20; CMake ≥ 3.20 + Ninja; doctest; no new third-party dependency.
- Layers only downward: `platform → app → game/render/ui/audio → script/core → assets`.
- No comments in code unless they carry non-obvious parity information.
- Game data stays read-only; never commit game assets.
- Docs UTF-8 without BOM; no NUL/literal `\n` artifacts.
- All real-data tests skip (`doctest::skip`) when `GL_GAME_DIR` is unset.

#include "gl/game/rginf.hpp"

namespace gl::game {
namespace {
bool is_leap(std::uint32_t year) {
    return (year % 4 == 0 && year % 100 != 0) || year % 400 == 0;
}

std::uint32_t days_in_month(std::uint32_t year, std::uint32_t month) {
    switch (month) {
    case 4:
    case 6:
    case 9:
    case 11:
        return 30;
    case 2:
        return is_leap(year) ? 29 : 28;
    default:
        return 31;
    }
}

std::uint32_t u32_from_bytes(const std::array<std::uint8_t, 0x20> &bytes, std::size_t index) {
    const std::size_t offset = index * 4;
    return static_cast<std::uint32_t>(bytes[offset]) |
           (static_cast<std::uint32_t>(bytes[offset + 1]) << 8) |
           (static_cast<std::uint32_t>(bytes[offset + 2]) << 16) |
           (static_cast<std::uint32_t>(bytes[offset + 3]) << 24);
}
} // namespace

GameDatetime GameDatetime::from_array(const std::array<std::uint32_t, 8> &value) {
    GameDatetime out;
    out.year = value[0];
    out.month = value[1];
    out.day = value[2];
    out.weekday = value[3];
    out.hour = value[4];
    out.minute = value[5];
    out.second = value[6];
    out.millisecond = value[7];
    return out;
}

GameDatetime GameDatetime::from_time_bytes(const std::array<std::uint8_t, 0x20> &value) {
    std::array<std::uint32_t, 8> fields{};
    for (std::size_t index = 0; index < fields.size(); ++index)
        fields[index] = u32_from_bytes(value, index);
    return from_array(fields);
}

std::array<std::uint32_t, 8> GameDatetime::to_array() const {
    return {year, month, day, weekday, hour, minute, second, millisecond};
}

bool datetime_le(const GameDatetime &lhs, const GameDatetime &rhs) {
    const std::array<std::uint32_t, 7> left{lhs.year, lhs.month, lhs.day, lhs.hour,
                                            lhs.minute, lhs.second, lhs.millisecond};
    const std::array<std::uint32_t, 7> right{rhs.year, rhs.month, rhs.day, rhs.hour,
                                             rhs.minute, rhs.second, rhs.millisecond};
    for (std::size_t index = 0; index < left.size(); ++index) {
        if (left[index] < right[index])
            return true;
        if (left[index] > right[index])
            return false;
    }
    return true;
}

GameDatetime add_days(const GameDatetime &value, std::int32_t days) {
    GameDatetime out = value;
    while (days > 0) {
        const std::uint32_t month_days = days_in_month(out.year, out.month);
        const std::int32_t remaining_in_month =
            static_cast<std::int32_t>(month_days - out.day);
        if (days <= remaining_in_month) {
            out.day += static_cast<std::uint32_t>(days);
            days = 0;
        } else {
            days -= remaining_in_month + 1;
            out.day = 1;
            ++out.month;
            if (out.month > 12) {
                out.month = 1;
                ++out.year;
            }
        }
    }
    return out;
}

RginfDecision decide_rginf(const gl::assets::SaveRginf &saved, const GameDatetime &now,
                           std::int32_t interval_days) {
    RginfDecision decision;
    const GameDatetime saved_ts = GameDatetime::from_array(saved.datetime);
    decision.due = saved.latch == 0 && datetime_le(add_days(saved_ts, interval_days), now);
    decision.runtime_latch = decision.due ? 1u : 0u;
    decision.timestamp = decision.due ? now : saved_ts;
    return decision;
}
} // namespace gl::game

namespace {
std::vector<gl::assets::InventoryItem>
convert_loot(const std::vector<LootItem> &items) {
    std::vector<gl::assets::InventoryItem> converted;
    converted.reserve(items.size());
    for (const LootItem &item : items) {
        gl::assets::InventoryItem entry{item.item_id,
                                        static_cast<std::uint32_t>(item.count),
                                        item.flags, item.type, item.style, 100,
                                        item.mod_count};
        entry.mods = item.mods;
        converted.push_back(std::move(entry));
    }
    return converted;
}

NpcInventoryCounts generate_npc_indices(
    InventoryRuntime &runtime, const std::vector<PersonInstance> &persons,
    const std::vector<std::size_t> &indices, gl::assets::GameVfs &vfs,
    const gl::assets::ItemNameIndex &names,
    InventoryRuntime::ItemTemplateLookup item_template, std::int32_t loot_level,
    MsvcRandom &rng, const gl::assets::SpecialDatabase *specials, bool force,
    bool consume_init_draws) {
    NpcInventoryCounts counts;
    counts.requested = indices.size();
    std::map<std::string, std::optional<gl::assets::InvTable>, std::less<>> cache;
    for (std::size_t index : indices) {
        const PersonInstance &person = persons[index];
        if (person.name == "Hero")
            continue;
        if (!person.inventory.empty()) {
            auto cached = cache.find(person.inventory);
            if (cached == cache.end()) {
                auto table = gl::assets::load_inv(vfs, person.inventory);
                if (!table) {
                    gl::log(gl::LogLevel::warning,
                            "npc inventory: cannot load '" + person.inventory +
                                "': " + table.error().message);
                    cached = cache.emplace(person.inventory, std::nullopt).first;
                } else {
                    cached = cache.emplace(person.inventory, std::move(table.value())).first;
                }
            }
            if (cached->second) {
                auto generated = NpcLootGenerator::generate(
                    *cached->second, loot_level, names, item_template, rng, specials, force);
                if (!generated) {
                    ++counts.gate_failed;
                } else {
                    runtime.replace_person_trade_items(person.name,
                                                       convert_loot(generated->hot));
                    runtime.replace_person_items(person.name,
                                                 convert_loot(generated->main));
                    ++counts.populated;
                }
            } else {
                ++counts.missing_table;
            }
        }
        if (consume_init_draws)
            consume_person_init_rng(person.def, rng);
    }
    return counts;
}
} // namespace

void generate_npc_inventories(...) {
    runtime.clear_persons();
    std::vector<std::size_t> indices(persons.size());
    for (std::size_t index = 0; index < indices.size(); ++index)
        indices[index] = index;
    generate_npc_indices(runtime, persons, indices, vfs, names, item_template,
                         loot_level, rng, specials, true, true);
}

NpcInventoryCounts regenerate_npc_inventories(...) {
    return generate_npc_indices(runtime, persons, indices, vfs, names,
                                item_template, loot_level, rng, specials, force, false);
}

New Game keeps the old `set_person_*` first-wins semantics (duplicate names stay first-wins); regeneration uses `replace_*` overwrite semantics (last-wins), matching the b1b2 restore behavior. The helper takes an explicit overwrite flag.
