# P3a — CS VM Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development or executing-plans. Steps: `- [ ]`.

**Goal:** Parse the original `.cs` bytecode, disassemble it, and execute core opcodes with globals and a dialog flow (`D_Say`/`D_Answer`) headlessly.

**Architecture:** `gl_assets` gains a `CS` bytecode parser and name tables. A new SDL-free `gl_script` library implements the VM, globals, native-function registry and dialog state. Tools: `glpak disasm-cs` and `glscript`.

**Tech Stack:** C++20, existing `gl_assets`/`gl_core`, doctest.

## Global Constraints

- C++20; `-Wall -Wextra -Werror`.
- `gl_assets`/`gl_script` SDL-free.
- `.cs` strings are cp1251 → UTF-8 at the API.
- Safety: step counter (10M), no unbounded recursion; malformed input → `format`.
- No game assets committed. Every task ends with a commit.

### Task 1: `.cs` parser + name tables (`gl_assets`)

**Interface:**
```cpp
namespace gl::assets {
struct CsNode {
    std::int32_t opcode = -1;
    std::int32_t a = -1, b = -1, c = -1, d = -1;
    std::array<std::int32_t, 9> args = {-1,...};
    std::string text;   // UTF-8 for str/str_var
    double value = -1.0;
};
Result<std::vector<CsNode>> parse_cs(std::span<const std::uint8_t> data);
const char* cs_opcode_name(std::int32_t opcode);
const char* cs_function_name(std::uint32_t id); // "D_Say", "RS_GetPersonParameterI", ... or "unknown"
bool cs_opcode_valid(std::int32_t opcode);
}
```
Parse per spec §3: `u32 size == data.size()`; nodes; payload rules; func args up to 9 terminated by -1; validate opcode; reject truncation/oversize. Strings: C-string cp1251 → UTF-8.

Tests: synthetic nodes all types; bad size/opcode/truncated; **all 555 real `.cs` from `scripts.pak` parse with 0 failures** (gated by `GL_GAME_DIR`).

### Task 2: VM core + globals (`gl_script`)

**Interfaces:**
```cpp
namespace gl::script {
using Value = std::variant<std::int32_t, std::uint32_t, double, std::string>;

struct ScriptGlobal { std::string type; std::string name; Value value; };
Result<std::vector<ScriptGlobal>> parse_globals(std::span<const std::uint8_t> data);

class ScriptHost {
public:
    virtual ~ScriptHost() = default;
    virtual Value call(std::uint32_t id, std::span<const Value> args) = 0;
};

enum class VmStatus { start, restart, continue_, wait_user, end, infinity };
class ScriptVm {
public:
    ScriptVm(std::vector<gl::assets::CsNode> nodes, ScriptHost& host);
    void set_globals(std::span<const ScriptGlobal> globals);
    void restart(bool reset_all);
    VmStatus status() const;
    bool step();                       // one node; false on wait/end/infinity
    std::uint64_t steps() const;
    Value* variable(std::string_view name);
    const std::map<std::string, Value>& variables() const;
};
}
```
Implement opcodes 0/2, 6..11, 14..18, 21..24, 48, 49, 50; type coercion per `CsExecutor`
(number comparisons cast to the left operand's type; string only ==/!=); assign sources;
jmp `d==-1` → wait/end; step counter; unknown opcode → `infinity`/error log.

Tests: synthetic node vectors for assign/arith/compare/logic/jmp; globals parser
(int/DWORD/float/string, comments, malformed lines); step limit.

- [ ] TDD, implement, commit.

### Task 3: Dialog flow + native registry (`gl_script`)

### Task 4: Tools (`glpak disasm-cs`, `glscript`)

- `glpak disasm-cs <game_dir> --file <path> [--out <txt>]`: parse via VFS, print
  `index: opcode name | a b c d | value/text | func name(args)`.
- `glscript --game-dir <dir> [--globals <path>] --file <path> [--run] [--answer N]`:
  parse; load globals (default `scripts/dialogs_special/zlato_vars.scr`); run to wait/end;
  print status, dialog ids, answers; `--answer N` feeds and continues; exit codes 0/1/2/3.
- Tests: `glpak disasm-cs` on `demon.d1.age.cs` non-empty; `glscript --run` → `wait_user`;
  `--answer 0` → no crash; both gated by `GL_GAME_DIR`.
