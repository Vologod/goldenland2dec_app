# P2-15c4b — Save Slots and `game_save` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement task-by-task.

**Goal:** Add `--save-dir`, `--write-save-slot <n>` and console `game_save <n>` on top of the c4a snapshot write.

**Architecture:** `core` exposes `save_slot_path`; `glgame` resolves an overridable save directory used by scan/load/dump/write, refactors the c4a writer to accept a target path, writes slots, refreshes the `SaveManager`, and registers `game_save`.

**Tech Stack:** C++20, CMake + Ninja, doctest, `core`/`tools/glgame`.

**Spec:** `docs/specs/2026-11-16-p2-15c4b-save-slots-design.md`.

- [ ] **Step 5: Console `game_save`**

In the console registry (next to `saves`):

```cpp
        registry_.add("game_save", "write the loaded snapshot to a slot",
                      [this](gl::core::Args args) -> gl::Result<std::string> {
                          if (args.size() != 1)
                              return gl::Error{gl::ErrorCode::argument,
                                               "usage: game_save <slot>"};
                          int slot = -1;
                          if (!parse_int(args[0], slot) || slot < 0)
                              return gl::Error{gl::ErrorCode::argument,
                                               "usage: game_save <slot>"};
                          if (!loaded_payload_)
                              return gl::Error{gl::ErrorCode::io,
                                               "game_save: no loaded save payload"};
                          const fs::path path =
                              gl::core::save_slot_path(resolved_save_dir(), slot);
                          if (!write_loaded_save_to(path))
                              return gl::Error{gl::ErrorCode::io,
                                               "game_save: write failed"};
                          return "game_save: slot " + std::to_string(slot) +
                                 " written (" +
                                 std::to_string(fs::file_size(path, std::error_code{})) +
                                 " bytes)";
                      });
```

(`parse_int` accepts `std::string_view` in this file; adapt if the Args
element type differs.) Include `<system_error>` if needed.

```cpp
TEST_CASE("glgame --save-dir writes slots without touching real saves") {
    const char* game_dir = std::getenv("GL_GAME_DIR");
    REQUIRE(game_dir != nullptr);

    TempDir temp;
    const fs::path config = write_test_config(temp.path);
    const fs::path save_dir = temp.path / "Saves";
    fs::create_directories(save_dir);
    const fs::path source = fs::path(game_dir) / "Saves" / "slot0.sav";
    const fs::path copied = save_dir / "slot0.sav";
    fs::copy_file(source, copied);
    const std::string real_before = read_file(source);
    const std::string copied_before = read_file(copied);

    const fs::path png = temp.path / "slot_write.png";
    std::string output;
    const int code = run_glgame_capture(
        screenshot_arguments(game_dir, config, png,
                             {"--save-dir", save_dir.string(), "--load-save", "0",
                              "--write-save-slot", "1", "--save-title", "SlotOne",
                              "--seed", "1"}),
        output);
    CAPTURE(code);
    CAPTURE(output);
    CHECK(code == 0);
    CHECK(output.find("save write: path=") != std::string::npos);
    CHECK(read_file(source) == real_before);
    CHECK(read_file(copied) == copied_before);
    const fs::path written = save_dir / "slot1.sav";
    REQUIRE(fs::exists(written));
    const std::string bytes = read_file(written);
    const auto payload = gl::assets::parse_save_payload(
        std::span<const std::uint8_t>(
            reinterpret_cast<const std::uint8_t *>(bytes.data()), bytes.size()));
    REQUIRE(payload.has_value());
    CHECK(payload->header.title == "SlotOne");
    CHECK(payload->info.level_id == "L93_4");
}

TEST_CASE("glgame console game_save writes a slot") {
    const char* game_dir = std::getenv("GL_GAME_DIR");
    REQUIRE(game_dir != nullptr);

    TempDir temp;
    const fs::path config = write_test_config(temp.path);
    const fs::path save_dir = temp.path / "Saves";
    fs::create_directories(save_dir);
    fs::copy_file(fs::path(game_dir) / "Saves" / "slot0.sav",
                  save_dir / "slot0.sav");

    const fs::path png = temp.path / "game_save.png";
    std::string output;
    const int code = run_glgame_capture(
        screenshot_arguments(game_dir, config, png,
                             {"--save-dir", save_dir.string(), "--load-save", "0",
                              "--exec", "game_save 2", "--save-title", "ConsoleSave",
                              "--seed", "1"}),
        output);
    CAPTURE(code);
    CAPTURE(output);
    CHECK(code == 0);
    CHECK(output.find("game_save: slot 2 written") != std::string::npos);
    REQUIRE(fs::exists(save_dir / "slot2.sav"));
}
```
