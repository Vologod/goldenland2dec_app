## Текстовые примитивы (подтверждены дизассемблером)

- `FUN_12030980` (RVA `0x30980`) — `TextOutA(hdc, x, y, text)`;
  `y` = верх клетки символа.
- `FUN_12030a88(this, hdc, x, y, textId, widthBox, heightBox)` (RVA
  `0x30a88`, `ret 0x18`). Локализованный текст по id. Если
  `widthBox != -1` и `textW < widthBox`: `x += (widthBox - textW) >> 1`;
  если `heightBox != -1` и `cellH < heightBox`:
  `y += (heightBox - cellH) >> 1`, где `cellH = abs(*(*font+8))`.
  `-1` = без центрирования (лево/верх).
- `FUN_12030b4c(...)` (RVA `0x30b4c`) и `FUN_12030a04(...)` (RVA
  `0x30a04`) — то же центрирование для строки и числа.
- Уточнение против декомпилятора: сигнатура `FUN_12030a88` содержит 6
  стек-аргументов (`ret 0x18`); декомпилятор показал 4. Порядок:
  `hdc, x, y, textId, widthBox(-1=нет), heightBox(-1=нет)`.

## Вертикальное выравнивание (GDI cell)

- GDI `TextOutA(hdc, x, y, ...)` при `TA_TOP`: `y` = верх клетки,
  baseline = `y + tmAscent`. Порт `Font::draw_text(y)` ставит
  baseline = `y + hhea_ascent`; `hhea`-ascent не включает line leading,
  поэтому текст листа оказывается выше оригинала («прижат к верху»).
- Замер (diff против фонового BMP, извлечённого `glpak extract`;
  y-диапазон пикселей текста) **до** фикса:
  - метки/значения: на 2–5 px выше (`Уровень` orig `107..122` vs
    port `104..119`; `40` orig `107..118` vs `105..116`);
  - заголовки: на 2 px выше (`СОПРОТИВЛЕНИЕ` orig `58..71` vs
    `56..69`).
- **Фикс:** `y += (Font::line_height() - Font::text_height()) / 2`
  (половина line leading) в `draw_text_rect`. После фикса:
  - метки/значения: расхождение 0–1 px;
  - заголовки/группы навыков: 1 px ниже;
  - страница навыков: 1–2 px.
- Метод: `glpak extract ... inventory_secondary.bmp / inventory_skills.bmp`,
  сравнение `.local/p7b2/characteristics.png` и `.local/p7b2/skills.png`
  с порт-рендером по пикселям текста (diff > 60).

## Остаточные расхождения

- Начертание: `pala.ttf` vs системный Palatino Linotype, weight 500/600
  не воспроизводится (stb_truetype без синтетического веса).
- Вертикальная привязка: доработана half-leading поправкой (см. выше);
  остаточный сдвиг ~±1 px (строки 1 px выше, заголовки 1 px ниже).
- `БОЕВЫЕ ХАРАКТЕРИСТИКИ` при 17 px ≈239 px > widthBox 228 →
  лево-выравнивание с `x=352` (≈+5 px к центру 466); следствие ширины
  `pala.ttf`, не координат.
- Клип меток строк убран: оригинал (`TextOutA`) не клипует, а самые
  длинные метки при 16 px помещаются (`Шанс критического удара` ~191 px
  в промежутке ~283 px; `Дробящее повреждение` ~180 px; `Рукопашный
  бой` ~129 px в ~162 px).
- Значения данных (эффективные статы, пулы очков) не менялись.
