# Research: P2c save headers

Дата проверки: 2026-10-20.
Источник: `I:\Games\Златогорье-2\Saves` (28 файлов `slot<N>.sav`; `Вертас.hero` не `.sav`).
Инструмент: побайтовый разбор файлов; строки декодированы cp1251.

## Подтверждено

- Все 28 `slot<N>.sav` имеют magic `"Goldenland II save \0"` (20 байт) и `version == 17`.
- Заголовок занимает 112 байт; title — 64 байта с offset 40, cp1251, NUL-terminated.
- `year/month/day` в заголовке совпадают с датой файла (проверены все 28 слотов).
- `slot0.sav` — title `Quick save`, 2022/11.
- `slot16.sav` — 2013/02, title `Убмйство кукуя`.
  Сырые байты title: `D3 E1 EC E9 F1 F2 E2 EE 20 EA F3 EA F3 FF`.
  Похоже на искажённое `Убийство кукуя` (байт `EC`/`м` вместо `E8`/`и`).
- `slot25.sav` — 2013/02, title `Продаем артифакты`.
  Сырые байты title: `CF F0 EE E4 E0 E5 EC 20 E0 F0 F2 E8 F4 E0 EA F2 FB`.
  Похоже на опечатку вместо `Продаём артефакты`.

Парсер `parse_save_header` не исправляет содержимое title: байты cp1251 переводятся в
UTF-8 как есть. Исправление/нормализация заголовков не входит в P2c.

## Наблюдения `--list-saves` (2026-10-20)

Команда `glgame --game-dir "I:\Games\Златогорье-2" --list-saves` — exit 0, 28 строк
(по одной на каждый `slot<N>.sav`). Выборочные строки (формат
`slot<N>\tYYYY-MM-DD\t<title>\t<size bytes>`):

```
slot0	2022-11-06	Quick save	642409
slot16	2013-02-12	Убмйство кукуя	433553
slot25	2013-02-12	Продаем артифакты	474281
```

Дата в выводе берётся из заголовка (год/месяц/день), размер — фактический размер файла.
Заголовки слотов 1–27, кроме 16 и 25, — короткие числовые строки (`1`, `29`, `10`, …);
это исходные данные игры, не ошибка парсера.

## Ранее ошибочные ожидания

В первой редакции spec/plan для `slot16` ожидался `Семейство`, для `slot25` —
`Прохождение`. Этих строк нет ни в одном файле (проверены cp1251 и UTF-16); ожидания
исправлены на фактические данные выше.
